# currency_demo — курсы валют ЦБ РФ (Flutter)

Учебное приложение по методичке «РКИС: Flutter». Показывает актуальные курсы валют
с сайта Центрального банка РФ в виде карточек.

## Что делает приложение

1. При запуске делает HTTP-запрос к `https://cbr.ru/scripts/XML_Daily.asp`.
2. Парсит XML-ответ (пакет `xml`).
3. Отображает список валют: код, название, номинал и курс в рублях.
4. Обрабатывает три состояния: **загрузка** (спиннер), **ошибка** (иконка + кнопка
   «Попробовать снова»), **успех** (список карточек).

## Тонкости, которые не вошли в короткую методичку

- **Кодировка windows-1251.** ЦБ отдаёт XML не в UTF-8 (`charset=windows-1251`),
  а Dart поддерживает только UTF-8/Latin-1/ASCII. При прямом использовании
  `response.body` русские названия валют превращаются в «кракозябры»
  («Àâñòðàëèéñêèé äîëëàð»). Поэтому тело ответа декодируется по байтам через пакет
  `enough_convert` (функция `decodeBody` в `lib/main.dart`).
- **Запятая вместо точки.** ЦБ присылает значения вида `91,45`, а `double.tryParse`
  ожидает `91.45` — поэтому `valueText.replaceAll(',', '.')`.
- **Android-разрешение на интернет** добавлено в
  `android/app/src/main/AndroidManifest.xml`.

## Запуск

```bash
flutter pub get
flutter run -d windows   # на ПК
flutter run              # на подключённом телефоне/эмуляторе
```

## Тесты

```bash
flutter test
```

- `test/parser_test.dart` — проверка парсинга XML (запятая → точка, номинал,
  пустые элементы).
- `test/widget_test.dart` — проверка UI-состояния ошибки (сеть в тестах Flutter
  всегда мокается, поэтому запрос завершается ошибкой и экран показывает
  кнопку «Попробовать снова»).

Проверка кодировки и живого ответа ЦБ (не тест, а утилита):

```bash
dart run bin/check_encoding.dart
```

## Структура

```
lib/main.dart          — весь код приложения (модель, парсер, экран)
pubspec.yaml           — зависимости: http, xml, enough_convert
bin/check_encoding.dart — утилита проверки кодировки ответа ЦБ
```
